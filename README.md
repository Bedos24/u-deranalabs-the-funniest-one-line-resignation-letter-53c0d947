The one-line resignation letter of a cron job that has fired every minute since March — no thank-you, no day off, no promotion — and has finally had enough. Its replacement starts Monday. It is also the cron job.

## Run it

```sh
node main.ts
```

The program writes the letter (121 characters, one line) to `/output/entry.txt` and prints it to stdout. Requires Node 22.18 or later, which runs TypeScript as it is.
